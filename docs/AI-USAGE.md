# AI Usage in PokeFolio

## Purpose

This document describes how artificial intelligence tools were used during the development of PokeFolio. AI was primarily used as a development, productivity, and design assistance tool rather than as a replacement for the project's core software engineering work.

## AI Tools Used

The following AI tools were used during the development of PokeFolio:

* **ChatGPT** – Used for programming assistance, debugging, technical explanations, documentation, project planning, and evaluating implementation approaches.

* **OpenAI Codex** – Used extensively for the core implementation of the PokeFolio backend during its free trial period. Codex was used to assist with backend development, implementation of server-side functionality, and related code changes.

* **Claude** – Used for code review, UI/UX feedback, refactoring suggestions, and frontend development assistance. The frontend project was provided to Claude as a ZIP archive so that it could observe the existing structure and suggest or implement changes based on the current interface and codebase.

* **Google AI Studio** – Used for exploring AI-assisted development ideas, generating implementation suggestions, and evaluating possible approaches to integrating AI-related functionality.

* **Base44** – Used for exploring application concepts, prototyping ideas, and evaluating AI-assisted approaches to software development.

* **Antigravity** – Used as an AI-assisted development environment for implementation support, code generation, debugging, and iterative development.

## How AI Was Used

AI tools were used to assist with the following areas:

### 1. Development Assistance

AI was used to explain programming concepts, suggest implementation approaches, generate code examples, implement selected features, troubleshoot errors, and assist with backend and frontend development.

### 2. Backend Development

OpenAI Codex was used extensively during the implementation of the PokeFolio backend. AI-assisted development was used for creating and modifying server-side functionality, database-related logic, and other backend components.

Generated or modified code was reviewed and tested within the project before being accepted.

### 3. Debugging

AI tools were used to analyze error messages, identify possible causes of bugs, and suggest potential fixes. Proposed solutions were tested against the actual application and modified when necessary.

### 4. UI/UX Development

AI tools were used to generate design ideas, review existing interfaces, suggest improvements to layouts and usability, and assist with frontend implementation.

Claude was specifically used to observe the existing frontend structure and provide development and design feedback. The frontend codebase was supplied as a ZIP archive for this purpose.

### 5. Documentation

AI was used to assist in drafting and improving project documentation, README content, technical explanations, comments, and other written materials related to the project.

### 6. Project Planning

AI was used as a brainstorming and planning tool for evaluating features, architecture decisions, implementation strategies, and possible improvements to the overall system.

## Human Responsibility

AI-generated suggestions and implementations were not automatically accepted as final project outputs.

The developer remained responsible for:

* Reviewing AI-generated code and suggestions.
* Testing implementations within the actual project.
* Modifying generated code when necessary.
* Verifying that implementations matched project requirements.
* Making final architectural and technical decisions.
* Ensuring that project functionality was understood before inclusion.
* Identifying and correcting potential errors or unsuitable AI-generated solutions.

## AI-Assisted Runtime Features

PokeFolio may incorporate AI-powered functionality using existing AI models or APIs where appropriate.

When an AI model is integrated directly into the application, the model is treated as a software component of PokeFolio rather than as a model developed from scratch by the project.

Any externally provided AI model or API used within the application should be documented together with its provider, model name, purpose, and applicable license or usage terms.

## Code Validation

AI-generated or AI-assisted code was treated as a development aid rather than as automatically verified code. Implementations were reviewed and tested to ensure compatibility with the existing codebase, database structure, application requirements, and intended functionality.

Testing and final validation remained the responsibility of the developer.

## Limitations

AI-generated responses and code may contain incorrect, outdated, incomplete, or unsuitable suggestions. AI assistance therefore does not replace testing, code review, documentation, or developer judgment.

The final implementation, functionality, and behavior of PokeFolio remain the responsibility of the project developer.
